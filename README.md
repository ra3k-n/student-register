# سجل الطلاب

تطبيق ويب يعمل بدون إنترنت (PWA) لتسجيل درجات الطلاب وحضورهم على شعب أو فصول، مع جدول حصص، ونسخ احتياطي واستعادة.

## النسخة المجانية والنسخة السنوية
- المجانية: شعبة واحدة، حتى 25 اسماً.
- السنوية: بلا حدود، وتُفعَّل بكود خاص بجهاز كل معلم.

## الخصوصية
بيانات الطلاب تُحفظ في جهاز المعلم فقط ولا تُرفع لأي خادم.

## للمالك
أداة توليد أكواد التفعيل: `tools/code-generator.html` (تعمل بدون إنترنت). لا ترفع المفتاح الخاص إلى GitHub.
